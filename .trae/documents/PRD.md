# 铁记 - 健身记录应用 PRD

## 1. 产品概述
一个装在手机上的健身记录工具，打开就能直接记录每次训练用了什么动作、什么器械、多重重量、几组几次。数据存在手机本地，随时可以导出给Trae分析训练效果。

## 2. 核心功能

### 2.1 今日训练（首页）
- **快速记录表单**：动作名称（输入或从常用动作选择）、器械名称、重量(kg)、组数、次数
- **今日训练清单**：显示今天已记录的所有条目，可删除
- **一键重复**：点击历史条目直接复制数据，改个重量就能再记一组

### 2.2 历史记录
- **按日期查看**：日历样式，有记录的日期高亮
- **某日详情**：展开看当天所有训练内容
- **训练统计**：显示当日总容量（重量×组数×次数）

### 2.3 导出数据
- **JSON导出**：完整数据，给Trae分析用
- **CSV导出**：表格格式，方便在Excel里查看
- **导出范围**：全部历史或仅本月

## 3. 页面结构
| 页面 | 内容 |
|-----|------|
| 今日训练 | 输入表单 + 今日已记清单 |
| 历史记录 | 日历 + 训练详情卡片 |
| 导出数据 | 格式选择 + 导出按钮 |

## 4. 设计风格
- **深色主题**：黑底白字，健身房光线通常较暗，深色更护眼也更省电
- **强调色**：荧光绿(#39ff14)，用于按钮和重点数据，一眼就能看到核心信息
- **大触控区**：所有按钮和输入框都足够大，带着手套或手抖也能点到
- **字体**：标题用力量感的窄体(Bebas Neue)，数字用等宽字体方便对齐
- **无动画干扰**：记录过程要干脆利落，不拖泥带水

## 5. 数据存储
- 所有数据存在手机本地（IndexedDB），不需要网络，不需要账号
- 换手机或清理浏览器数据会丢失，所以提供了导出备份功能
